# 提交审核材料（每次发版照抄）

> 更新时间：2026-11-05 · 当前线上版本：1.0.0 · 待审版本：1.0.1

## 版本描述

### 标准版（提审用）

播了么——抖音主播开播提醒工具。用户添加关注的主播抖音号后，云端每分钟自动巡检直播状态，开播时通过微信订阅消息推送提醒。

本版本新增：首页大屏支持多位关注主播自动轮播展示（可滑动切换、开播的主播自动上屏）；订阅页展示可推送额度（含已推送次数），额度随订阅行为自动增减；优化页面顶部配色的视觉过渡。修复部分入口添加关注后用户标识缺失的问题。

无支付、无广告、无敏感信息收集，仅使用订阅消息基础能力。

### 精简版

抖音主播开播提醒：关注主播后由云端自动巡检，开播时经微信订阅消息推送提醒。本次增加大屏轮播展示、额度可视化与若干稳定性修复。

## 类目建议

「工具 > 信息查询」或「效率 > 提醒/日程」

## 发版 SOP（顺序敏感）

```powershell
$env:TCB_ENV_ID  = 'bome-livedongyailongwang-d91c6e8'
$env:SUBS_TEMPLATE_ID = 'N923NAse66knou-8SdrzLwYjQqtE5vVCoL3jqYn6aQo'
npm run build:weapp        # 自带 sync-cloud-shared 前置
node scripts/doctor.js     # 产物注入体检
& "C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" upload `
  --project "D:\小程序" -v <新版本号> -d "<版本描述>"
```

后台步骤：mp.weixin.qq.com → 版本管理 → 提交审核 → 审核通过点发布。

⚠️ **提审会复用上次表单值**：同一版本若提审过（含撤回），直接点「提交审核」会用上次的版本描述秒提，不给编辑机会。
要改描述必须直开表单页 `/wxamp/wadevelopcode/get_class?action=get_class&token=…&openid=…&user_name=…`，
用原生 setter 改 textarea 并派发 input（React 受控），确认计数器变化后再点提交。
带错文案已提交的，走「审核版本 → ∨ → 撤回审核」（未进审核系统时撤回只是重新排队）。

注意：**云函数部署不走审核**（即时生效），所以云端侧改动随时可部署；只有前端代码变更需要走版本审核。
另：修改「介绍」「用户隐私保护指引」需微信验证（扫码），提审本身不需要。
